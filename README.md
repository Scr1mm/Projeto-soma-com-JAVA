# 🧮 Calculadora de Soma em Java

Uma aplicação de terminal desenvolvida em Java que funciona como uma calculadora especializada em somar **quatro números inteiros** informados pelo usuário.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Java (JDK 8 ou superior)
* **Biblioteca Padrão:** `java.util.Scanner` para entrada de dados via console

---

## ⚙️ Funcionalidades

* 📥 **Entrada Interativa:** Solicita quatro números inteiros em sequência no terminal.
* ➕ **Processamento de Soma:** Realiza o cálculo aritmético com precisão.
* 📤 **Exibição do Resultado:** Apresenta o valor total formatado na tela.

---

## 🚀 Como Executar o Projeto

### Pré-requisitos

* Ter o **JDK (Java Development Kit)** instalado em seu sistema.


1. **Compile a classe principal:**

javac Soma.java




2. **Execute a calculadora:**

java Soma



💻 Exemplo de Execução

Digite o primeiro número: 15
Digite o segundo número: 25
Digite o terceiro número: 10
Digite o quarto número: 50
A soma é: 100

```
